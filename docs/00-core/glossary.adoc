== Glossary

=== Discord Domain

[cols="1,4",options="header",stripes=odd]
|===
|Term |Definition

|*User*
|A Discord account identified by a UUID, username, display name, and UTC join date. A user
may belong to multiple guilds and hold multiple roles in persistence.

|*Guild*
|A Discord community identified by a UUID, name, optional description, and UTC creation
date. It owns roles and channels and has members.

|*Role*
|A named, colored, ordered permission grouping that belongs to exactly one guild. Permission
behavior itself is outside the current implementation.

|*Channel*
|An ordered communication space that belongs to exactly one guild.

|*ChannelType*
|The domain enumeration of supported channel kinds: `TEXT` and `VOICE`.
|===

=== Contracts and Persistence

[cols="1,4",options="header",stripes=odd]
|===
|Term |Definition

|*Domain record*
|An immutable, framework-independent Java record representing the simple fields of a
Discord resource.

|*JPA entity*
|The PostgreSQL persistence representation. Entities contain JPA relationships and must
not be returned directly by the future REST API.

|*Repository*
|A Panache repository keyed by `UUID` for loading and persisting one entity type.

|*Create request*
|A Java record containing client-editable fields required at creation. UUIDs and dates are
generated server-side; Role and Channel creation additionally carry `guildId`.

|*Update request*
|A Java record for a full update of editable fields. It cannot replace IDs, generated
dates, or existing relationships.

|*Response DTO*
|A Java record exposing simple fields and relation UUIDs. It never exposes an entity or a
Hibernate collection.

|*Mapper*
|A stateless utility that converts between request, domain, persistence, and response
representations. It performs no repository lookup.
|===

=== Architecture and Testing

[cols="1,4",options="header",stripes=odd]
|===
|Term |Definition

|*REST endpoint*
|An HTTP operation handled by a JAX-RS resource. Discord CRUD endpoints are planned for
ticket #17 and do not exist in the current revision.

|*Bean Validation*
|Jakarta constraints such as `@NotBlank`, `@NotNull`, and `@PositiveOrZero` applied to
incoming DTOs and persistence fields.

|*ArchUnit*
|Executable rules that verify domain isolation, permitted layer dependencies,
statelessness, and naming conventions.

|*Testcontainers*
|The test library that starts an ephemeral PostgreSQL instance for integration tests. It
does not use the project's persistent database or volume.

|*Living documentation*
|AsciiDoc and PlantUML sources rendered to HTML and PDF by the Maven `docs` profile.
|===
