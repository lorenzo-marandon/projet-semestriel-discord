[.lead]
`discord-api` is a Quarkus and Java 21 project that currently implements the Discord
domain, PostgreSQL persistence mappings, API DTO contracts, mapping utilities, validation,
and automated architecture and integration tests.

[IMPORTANT]
====
Discord CRUD REST resources and application services are not implemented in the current
revision. They begin with ticket #17. Diagrams and component descriptions in this document
therefore distinguish the implemented foundation from planned HTTP functionality.
====
